# Subhro Pal - Portfolio

A premium, highly interactive portfolio website showcasing expertise in **Data Science**, **Machine Learning**, and **Generative AI**. 

Built with a focus on rich aesthetics, high-performance animations, and full responsiveness across all devices.

---

## ✨ Premium Features

- **Dynamic Hero Section**: Interactive data-network canvas with mouse-repel physics and real-time animation.
- **Premium Animations**: 
  - **GSAP & Framer Motion**: Silky smooth reveals and transitions.
  - **GSAP ScrollToPlugin**: Premium programmatic scrolling for navigation links.
  - **Magnetic Buttons**: Interactive UI elements that follow your cursor.
  - **3D Tilt Cards**: Perspective-aware project and service cards.
  - **Infinitely Scrolling Marquee**: A custom, high-performance tech stack display.
- **Full Responsiveness**: Optimized from 320px phones to ultra-wide PC monitors.
- **Interactive Lightbox**: Full-screen certificate previews for professional validation.
- **Modern Dark UI**: Glassmorphism aesthetic with polished gradients and ambient glows.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn/ui
- **Animation**: GSAP (GreenSock), Framer Motion, Lucide Icons
- **Data/AI Focus**:
  - **Languages**: Python, SQL
  - **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, scikit-learn
  - **Deep Learning**: PyTorch, TensorFlow, Keras
  - **Generative AI**: LLaMA, Stable Diffusion, HuggingFace, NLP
  - **Deployment**: FastAPI, Streamlit

## 🚀 Featured Projects

- **CONTRA**: Advanced ML ensemble prediction system.
- **ORBITUNE**: AI-powered NLP system leveraging LLaMA for content discovery.
- **Reservoir Forecasting**: Predictive analytics for water resource management using time-series ML and Power BI.

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / bun

### Installation

```sh
# Clone the repository
git clone https://github.com/SHHUUBBH/PORTFOLIO.git

# Navigate to project directory
cd PORTFOLIO

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```sh
# Create production build
npm run build

# Preview production build
npm run preview
```
